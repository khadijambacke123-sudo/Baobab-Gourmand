# 🍽️ Le Baobab Gourmand

## Description

Ce projet est un site web pour un restaurant africain.
Il permet aux utilisateurs de découvrir les plats, en savoir plus sur le restaurant et contacter le service.

##  Pages du site

* Accueil
* Menu
* À propos
* contact

##  Technologies utilisées

* HTML5
* CSS3
* Bootstrap
* JavaScript

## Structure du projet

* index.html → page d’accueil
* menu.html → liste des plats
* about.html → présentation du restaurant
* contact.html → formulaire de contact
* css/ → fichiers de style
* images/ → images du site

## Installation

1. Télécharger le projet
2. Ouvrir le fichier `index.html` dans un navigateur

## Fonctionnalités

* Affichage des plats
* barre de recherche pour le menu
* Navigation entre les pages
* Formulaire de contact
* le bouton de retour en haut
* Design responsive
